# Bon Temps calendar files

Copies of the per-event calendar files from [Bon Temps](https://brody-robicheaux.github.io/bon-temps/)
([project](https://github.com/brody-robicheaux/bon-temps)).

Why a separate site: when Bon Temps is added to an iPhone's Home Screen, links to its own address
open inside the app's bare window, which can't handle calendar files (it shows a blank page). Links
to a different address open in a Safari window, which shows "Add to Calendar". So the Home Screen
app's **Apple Calendar** button points here.

The *Copy calendar files* workflow copies the latest files from Bon Temps every 20 minutes.
Nothing here needs editing by hand.
